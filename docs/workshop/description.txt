[h1]Install (once, about two minutes)[/h1]
[img]https://raw.githubusercontent.com/xD3I/PZ_Optimization/master/docs/workshop/images/40-install.gif[/img]
[olist]
[*]Subscribe, let Steam download it.
[*]Mods (main menu): enable [b]PZ_Optimization[/b]; a window shows your install command.
[*][b]Copy the command[/b], paste it into PowerShell (Windows) or a terminal (Linux, macOS), Enter.
[*]Quit the game; the installer copies the files when it has closed.
[*]Start the game, disable the mod again. Options has a new [b]PZ Optimization[/b] tab.
[/olist]
No window? Windows: [code]irm https://github.com/xD3I/PZ_Optimization/releases/latest/download/install.ps1 | iex[/code]
Linux, macOS: [code]curl -fsSL https://github.com/xD3I/PZ_Optimization/releases/latest/download/install.sh | bash[/code]

[h1]Updates, uninstall[/h1]
Updates arrive in the main menu (PZ OPTIMIZATION UPDATE, one click). To remove: Options > PZ Optimization > [b]Uninstall PZ Optimization[/b], [b]before[/b] you unsubscribe (unsubscribing leaves the installed files). After unsubscribing: the install command with [b]-Uninstall[/b] (Windows) or [b]| bash -s -- --uninstall[/b] (Linux, macOS).
